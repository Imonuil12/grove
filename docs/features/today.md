# Today

**Status:** ✅ shell in Milestone 1, real data in Milestones 2–4 · The home screen after sign-in.

## Purpose
One place that answers "what should I do today?" so users never have to navigate to act.

## Layout
1. **Today's habits**: one-tap check-ins, ordered by planned time (HAB-3)
2. **Reading**: the current book, progress bar, "log a session" button; recall questions due (LRN-2)
3. **Training**: this week's ring (FIT-1) and today's planned workout
4. **Coach nudge**: one line from the coach, linking to the weekly review
5. **Your tree**: the bonsai (Focused mode) or XP and companions (Game mode)

## Milestone 1 scope
The page and empty states only ("Create your first habit", "Add a book", "Log a workout"), each linking to
its tracker page. Real data arrives with Milestones 2–4.
